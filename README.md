# Симплекс-метод для лінійного програмування

## Опис

Реалізація класу `SimplexSolver` для розв'язання задач лінійного програмування на **максимізацію** за допомогою стандартного **симплекс-методу** (метод Данціга).

## Особливості

- ✅ **Без похибок округлення**: використовує `fractions.Fraction` для точних обчислень
- ✅ **Автоматичне додавання слабких змінних**: нерівності типу `≤` перетворюються у рівняння
- ✅ **Підтримка дробових коефіцієнтів**: коректна робота з раціональними числами
- ✅ **Детальні результати**: повертає оптимальне рішення, значення цільової функції, кількість ітерацій
- ✅ **Валідація вхідних даних**: перевірка коректності розмірів матриць

## Математична формулювання

Клас розв'язує задачу виду:

```
max c^T * x
s.t. A*x ≤ b
     x ≥ 0
```

Де:
- `c` — вектор коефіцієнтів цільової функції (n елементів)
- `A` — матриця коефіцієнтів обмежень (m × n)
- `b` — вектор правих частин обмежень (m елементів)
- `x` — вектор змінних (n елементів)

Система автоматично перетворюється в канонічний вигляд:
```
A*x + s = b
x ≥ 0, s ≥ 0
```
де `s` — вектор слабких змінних.

## Використання

### Базовий приклад

```python
from simplex_solver import SimplexSolver
from fractions import Fraction

# Задача: max 3x₁ + 2x₂
#         s.t. 2x₁ + x₂ ≤ 100
#              x₁ + x₂ ≤ 80
#              x₁, x₂ ≥ 0

A = [[2, 1], [1, 1]]
b = [100, 80]
c = [3, 2]

solver = SimplexSolver(A, b, c)
result = solver.solve()

print(f"Статус: {result['status']}")
print(f"x₁ = {result['x'][0]}")
print(f"x₂ = {result['x'][1]}")
print(f"Максимальне значення z = {result['objective_value']}")
```

**Результат:**
```
Статус: optimal
x₁ = 20
x₂ = 60
Максимальне значення z = 180
```

### Робота з дробовими коефіцієнтами

```python
from fractions import Fraction

# max (1/2)x₁ + (3/2)x₂
# s.t. x₁ + x₂ ≤ 4

A = [[1, 1]]
b = [4]
c = [Fraction(1, 2), Fraction(3, 2)]

solver = SimplexSolver(A, b, c)
result = solver.solve()

# Результат точний без похибок округлення
print(f"x₂ = {result['x'][1]}")  # 4
print(f"z = {result['objective_value']}")  # 6
```

### Отримання результатів

```python
# Точні значення (Fraction)
result_fraction = solver.get_solution_as_fraction()

# Наближені значення (float)
result_float = solver.get_solution_as_float()

# Доступні ключі в результаті
result['status']          # 'optimal', 'unbounded', або 'error'
result['x']              # Список значень для оригінальних змінних
result['objective_value'] # Оптимальне значення цільової функції
result['iterations']     # Кількість ітерацій симплекс-методу
result['all_variables']  # Значення всіх змінних (включаючи слабкі)
```

## API

### Конструктор

```python
SimplexSolver(A, b, c)
```

**Параметри:**
- `A`: Список списків (матриця m × n) — коефіцієнти обмежень
- `b`: Список (довжина m) — праві частини обмежень
- `c`: Список (довжина n) — коефіцієнти цільової функції

**Виключення:**
- `ValueError`: Якщо розміри матриці не відповідають

### Методи

#### `solve()`

Розв'язує задачу лінійного програмування.

**Повертає:** Словник з ключами:
- `status`: статус розв'язання ('optimal', 'unbounded', 'error')
- `x`: оптимальне рішення (список Fraction)
- `objective_value`: оптимальне значення цільової функції (Fraction)
- `iterations`: кількість ітерацій
- `all_variables`: значення всіх змінних з врахуванням слабких змінних

#### `get_solution_as_float()`

Повертає розв'язок з float значеннями.

#### `get_solution_as_fraction()`

Повертає розв'язок з точними Fraction значеннями.

#### `print_tableau()`

Виводить поточну симплекс-таблицю в читаному форматі.

## Приклади

### Приклад 1: Задача з 3 змінними

```python
# max 5x₁ + 4x₂ + 3x₃
# s.t. 2x₁ + 3x₂ + x₃ ≤ 5
#      4x₁ + x₂ + 2x₃ ≤ 11
#      3x₁ + 4x₂ + 2x₃ ≤ 8

A = [[2, 3, 1], [4, 1, 2], [3, 4, 2]]
b = [5, 11, 8]
c = [5, 4, 3]

solver = SimplexSolver(A, b, c)
result = solver.solve()

print(f"x = {[float(x) for x in result['x']]}")  # [2.0, 0.0, 1.0]
print(f"z = {result['objective_value']}")        # 13
```

### Приклад 2: Задача з від'ємними коефіцієнтами

```python
# max -x₁ + 3x₂
# s.t. x₁ + x₂ ≤ 10

A = [[1, 1]]
b = [10]
c = [-1, 3]

solver = SimplexSolver(A, b, c)
result = solver.solve()

print(f"x₁ = {result['x'][0]}")      # 0
print(f"x₂ = {result['x'][1]}")      # 10
print(f"z = {result['objective_value']}")  # 30
```

## Структура класу

### Приватні методи

- `_add_slack_variables()`: Додає слабкі змінні та будує симплекс-таблицю
- `_find_entering_variable()`: Вибирає змінну для введення в базис
- `_find_leaving_variable(entering)`: Вибирає змінну для виведення з базису
- `_pivot(entering, leaving_row)`: Виконує крок симплекс-методу (поворот таблиці)

### Властивості

- `tableau`: Поточна симплекс-таблиця (список списків Fraction)
- `basis`: Індекси базисних змінних
- `non_basis`: Індекси небазисних змінних
- `solution`: Оптимальне рішення
- `optimal_value`: Оптимальне значення цільової функції
- `iterations`: Кількість виконаних ітерацій

## Обмеження і зауваження

1. **Максимізація тільки**: Для задач мінімізації помножте коефіцієнти цільової функції на -1
2. **Нерівності типу ≤**: Система базується на обмеженнях виду ≤
3. **Невід'ємні змінні**: Задача припускає x ≥ 0
4. **Стартова база**: Використовуються слабкі змінні як початкова база
5. **Необмежені задачі**: Система виявляє необмежені задачи, але не обробляє всі можливі численні помилки

## Складність

- **Часова складність**: У гіршому випадку експоненціальна, але на практиці поліноміальна
- **Просторова складність**: O(m·n) для зберігання симплекс-таблиці

## Рекомендації

1. Для точних обчислень використовуйте `Fraction` замість float
2. Для великих задач розгляньте спеціалізовані бібліотеки (SciPy, PuLP)
3. Для задач мінімізації помножте коефіцієнти c на -1
